# 🚌 Smart Bus Tracking Platform

A full-stack **real-time bus tracking platform** designed to improve public transportation by allowing passengers to track buses, view routes, check estimated arrival times, and receive important travel updates.

The platform also provides transport administrators with tools to manage buses, drivers, routes, schedules, and tracking information.

## 🚀 Key Features

* 🚌 Real-time bus location tracking
* 📍 GPS-based bus tracking
* 🗺️ Route and stop management
* ⏱️ Estimated bus arrival times
* 👤 Passenger/user registration and login
* 🔐 Secure authentication
* 🚍 Bus and driver management
* 📊 Admin dashboard
* 🔔 Notifications and travel updates
* 📱 Responsive web interface
* 🔌 REST API integration

## 🏗️ System Architecture

The platform consists of three major components:

**Passenger → Web Application → REST API → MySQL Database**

**Bus/Driver → GPS Location → Backend → Real-Time Tracking → Passenger**

**Admin → Admin Dashboard → Backend API → Database**

## 🎯 Project Objective

The main objective of this project is to provide a reliable and user-friendly public transportation tracking system that reduces passenger waiting time and provides accurate information about bus locations and arrival times.
